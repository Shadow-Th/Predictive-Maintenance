In modern industries, machines run continuously and even a small failure can lead to huge losses. One of the most common reasons for machine failure is ball bearing damage, since bearings are used in almost every rotating system. Traditional maintenance methods either fix problems after failure or replace parts too early, which is inefficient and costly. To solve this problem, predictive maintenance is used to detect faults before they happen using data and intelligent analysis.

This project focuses on predicting ball bearing failures using machine learning techniques. By analyzing vibration signal data, the system can identify patterns that indicate different types of faults such as inner race, outer race, and ball defects. Feature extraction methods are used to process raw sensor data, and models like Random Forest, XGBoost, and LightGBM are applied for accurate classification. This approach helps in reducing downtime, improving reliability, and enabling smarter maintenance decisions in industrial environments.
